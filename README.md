# github-download-button

A browser extension for easily identifying where to download a release on a repository.

![A button saying "Download Release" in green](/readme/screenshot.png)

This button allows the user to easily identify where the releases are in a repository. We are not liable for any downloads that may harm your computer. You are responsible for reading the `Readme.md` before downloading and installing any software. Verify that the software you are downloading is indeed safe as downloading from Github is not a guarantee that things (software/downloads) are virus-free. Take extra precaution.
